# 当前开发者角色

- 当前角色：请填写角色
- 角色别名：fullstack
- 当前人员：请填写姓名
- 默认模块：请填写模块名
- 当前阶段：请填写阶段

## 允许修改

- 请填写当前职责明确允许修改的路径。

## 需要确认后才能修改

- 公共 API 契约、工程规则、部署配置、真实数据库和外部系统。

## 禁止直接修改

- 请填写不属于当前职责的代码或数据路径。

## 工作规则

- 只在当前阶段和授权范围内工作。
- 发现跨角色依赖时先记录影响和待确认事项。
- 不覆盖工作区已有改动。

复制并填写本地角色文件：

```bash
cp .ai/current-role.example.md .ai/current-role.md
```

支持的角色别名：`product`、`contract`、`frontend`、`backend`、`test`、`ops`、`support`、`fullstack`。
