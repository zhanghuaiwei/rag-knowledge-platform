# 企业通用化前端任务

## 前置门禁

- [ ] OIDC/BFF 形态、路由权限和 OpenAPI 版本已确认。
- [ ] web 工程建立，配置 lint/typecheck/test/E2E 命令。
- [ ] API client 与类型只从权威 OpenAPI 生成，页面不直接拼接完整请求地址。

## Gate 0：安全与契约

- [ ] 替换用户名密码 token 表单：采用 OIDC Code + PKCE 登录/回调/登出；处理 state、nonce、过期、取消和 IdP 错误。
- [ ] token 不落 localStorage；若采用 BFF，使用 Secure/HttpOnly/SameSite cookie 并实现 CSRF 防护。
- [ ] 路由和按钮权限仅用于体验，服务端拒绝仍按统一 401/403/404 处理；切换租户后清空跨租户缓存。
- [ ] 从 OpenAPI 生成 client/type/error map；加入契约版本检查，删除本地重复枚举和魔法 URL。
- [ ] 预览与下载分别展示：无 download 权限时不请求原始文件流；历史引用打开时重新处理授权失败/已撤回/已过期。
- [ ] SSE 处理 meta/token/sources/final/error、断连、取消、重复事件和会话归属；不得把未净化模型 HTML 直接渲染。

## 企业 MVP 体验

- [ ] 知识库向导包含所有者、业务域、审核、分类、保留、数据区域、模型策略和配额摘要。
- [ ] 文档列表显示来源、同步状态、版本、所有者、敏感级、审核、索引、新鲜度和权限状态，可定位失败阶段。
- [ ] 元数据表单由租户 schema 驱动，支持必填/枚举/日期/多值/引用校验以及批量编辑预览。
- [ ] 权限编辑器可解释继承来源和最终有效权限；高风险变更展示影响文档/成员数并要求确认。
- [ ] 问答显示来源版本、页/段、检索时间、置信/拒答状态和内容可能过期提示；反馈支持“错误、过期、无权限、引用不符”。
- [ ] 管理页提供 API Key scope/KB/期限、使用情况和吊销；明文只展示一次并明确复制确认。

## 通用化扩展体验

- [ ] 连接器中心按能力展示授权、范围、同步模式、源 ACL、区域和健康状态；OAuth 回调不暴露第三方 token。
- [ ] 同步任务展示游标时间、新增/更新/删除/失败数、新鲜度、限流状态，并支持安全重试/单对象重放。
- [ ] 治理中心支持分类、保留、法律保全、复审队列、删除审批和删除证明查询。
- [ ] 质量面板按租户/业务域/语言/权限角色展示检索、引用、拒答、延迟和成本，不把单一综合分掩盖细分退化。
- [ ] 所有批量、删除、发布、撤权、换模/重建索引操作先预览影响，显示 task 进度、可取消条件和失败恢复建议。

## 完成定义

- [ ] loading/empty/error/disabled/stale/partial-success/offline 状态完整。
- [ ] 组件级测试覆盖权限显示、错误映射、schema 表单和 SSE；Playwright 覆盖关键角色/租户/连接器路径。
- [ ] 可访问性达到 WCAG 2.2 AA 基线：键盘、焦点、语义、对比度、错误提示和流式内容播报可用。
- [ ] 敏感数据不进入前端日志、分析埋点、URL、缓存快照或错误上报；页面截图/测试数据已脱敏。
- [ ] typecheck、lint、test、E2E 和可见 UI 截图均有真实执行记录。
