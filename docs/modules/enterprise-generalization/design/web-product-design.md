## 1. 产品定位

面向 SaaS 与私有化共用的**通用企业知识库平台 Web 端**，服务两类心智：

1. **消费知识**：员工通过搜索与问答快速获得有引用、可追溯、权限正确的答案。
2. **经营知识**：知识所有者、审核员、管理员完成接入、治理、授权、质量运营与安全合规闭环。

产品化的核心差异点（相对内部工具）：

- **权限即体验**：所有页面按统一策略结果渲染，预览/下载/引用可解释，授权失败可理解、可申诉，而不是简单隐藏。
- **状态透明**：文档从隔离、扫描、解析到发布的每个阶段可见、可定位、可重试；异步任务有进度、可取消、有恢复建议。
- **可信问答**：每个答案携带来源版本、页/段、检索时间、置信度与"可能过期"提示，拒答是正常产品状态而非异常。
- **多租户一等公民**：租户切换是显式上下文切换，切换后全部缓存与数据域随之更换。

## 2. 目标用户与角色

| 角色 | 目标 | 高频场景 | 关键页面 |
| --- | --- | --- | --- |
| 普通员工（VIEWER） | 快速获得可信答案 | 问答、搜索、收藏、引用溯源 | 工作台、问答、搜索、文档预览 |
| 知识所有者/编辑（OWNER/EDITOR） | 维护知识库内容与质量 | 上传/同步、元数据补全、提交审核、处理失败 | 知识库详情、文档库、连接器、同步任务 |
| 审核员 | 控制发布质量 | 审核队列、批量通过/驳回、复审到期内容 | 治理中心-审核 |
| 知识管理员 | 治理与授权 | 元数据 schema、分类分级、保留/法律保全、ACL | 治理中心、权限编辑器 |
| 租户管理员 | 平台运营与安全 | 成员/组织、API Key、Webhook、审计、配额 | 管理中心 |
| 质量运营 | 持续评估检索与问答质量 | 质量面板、黄金集对比、退化告警 | 质量与用量 |

角色与权限点（`view_excerpt` / `view_content` / `download_original` / 管理动作）以契约评审为准；前端只消费策略结果，不自建权限语义。

## 3. 设计原则

1. **默认拒绝的 UI 表达**：无权限显示原因与申请入口；统一处理 401/403/404，不把"无权限"伪装成"不存在"或空白。
2. **先安全再可用**：无 `download_original` 不渲染下载按钮也不发起原始文件流请求；历史引用重新授权失败时明确提示"已撤回/已过期/无权限"。
3. **危险操作三段式**：预览影响（影响文档数/成员数）→ 确认 → task 进度与恢复建议；删除、发布、撤权、重建索引、吊销 Key 均适用。
4. **状态完备**：每个页面覆盖 loading / empty / error / disabled / stale / partial-success / offline；异步任务轮询或事件驱动，断线可恢复。
5. **契约驱动**：组件不直接 fetch、不拼接 URL、不本地复制枚举；类型与错误映射由 OpenAPI 生成（当前由 mock transport 过渡）。
6. **可访问性基线 WCAG 2.2 AA**：键盘可达、焦点可见、语义化标签、流式内容（SSE）有可播报的完成态。

### 4.2 全局框架元素

- **顶部栏**：全局搜索入口、租户切换器、通知（任务完成/审核待办/配额告警）、用户菜单。
- **租户切换器**：显式列出可访问租户；切换即重新建立上下文，前端清空旧租户全部缓存（React Query/SWR key 以 tenantId 为域）。
- **任务中心**（抽屉）：当前用户的异步任务（上传、同步、索引重建、删除），展示进度、可取消条件、失败恢复入口。

## 5. 核心页面设计

### 5.1 登录 / 租户选择（Gate 0）

- OIDC Authorization Code + PKCE；`/login` 仅一个"使用企业账号登录"入口，不渲染账号密码表单。
- `/auth/callback` 处理 state/nonce 校验、IdP 错误（access_denied、MFA 失败等）、过期与取消，均给出可恢复路径。
- 登录后若属于多租户，进入租户选择页；无租户时显示"等待管理员分配"空态。
- token 不落 localStorage；BFF 模式下使用 Secure/HttpOnly/SameSite Cookie + CSRF 防护（形态待确认，见 §9 方案对比）。

### 5.2 工作台 `/dashboard`

- 面向个人的聚合页：我的知识库、最近问答、收藏、待办（待我审核/待我补全元数据/同步失败）、平台公告（如知识库 stale 告警）。
- 空态按角色引导：员工引导首次提问；编辑引导创建知识库或接入连接器。

### 5.3 问答 `/chat`（产品核心页）

- **布局**：左侧会话列表（可归档、按知识库筛选）；右侧消息流 + 输入区；顶部显示当前会话作用的知识库范围。
- **流式回答**：SSE 处理 meta/token/sources/final/error；支持断连提示、取消生成、重复事件去重；模型输出按上下文净化后渲染，不直接插入未净化 HTML。
- **答案可信度**：每条答案展示置信度、引用列表（文档名 + 版本 + 页/段 + 检索时间）；低置信与拒答（NO_ANSWER / LOW_CONFIDENCE / BLOCKED）有明确的差异化视觉与建议动作（换问法/缩小范围/联系所有者）。
- **引用溯源**：点击引用 → 打开文档预览定位到页/段；重新授权失败时提示撤回/过期/无权限，不展示内容。
- **新鲜度提示**：引用来源超过复审期或被标记 stale 时，答案附带"信息可能过期"标识。
- **反馈**：👍/👎 + 结构化原因（错误、过期、无权限、引用不符），反馈写入评测闭环。
- **追问建议**：由服务端 suggestions 渲染，点击即发送。

### 5.4 搜索 `/search`

- 关键词 + 过滤器（知识库、文件类型、时间范围、敏感级、所有者）；结果含高亮摘要、页/段定位、更新时间。
- 摘要即 `view_excerpt` 权限面；"打开原文"需 `view_content`；"下载"需 `download_original`，三档分离展示。
- 空结果区分：无匹配 / 有匹配但无权限（显示可申请入口）/ 服务降级。

### 5.5 知识库 `/kbs`

- **列表**：卡片/表格双视图；展示文档数、分块数、我的角色、状态（ACTIVE/ARCHIVED/DELETING）、健康度与新鲜度徽标。
- **创建向导**（分步表单）：基本信息（名称、可见性）→ 归属（所有者、业务域）→ 治理（审核开关、元数据 schema、分类敏感级、保留策略）→ 策略（数据区域、模型路由策略、索引 profile 摘要）→ 配额摘要与确认。每步可保存草稿。
- **详情-概览**：文档/分块统计、问答健康度（无答案率、低置信率）、同步新鲜度、配额用量、近期失败任务。
- **详情-成员**：角色（OWNER/EDITOR/VIEWER）管理；高风险变更（移除最后一个 OWNER）预览影响并二次确认。

### 5.6 文档库与文档详情

- **文档列表**：状态列为设计重点——来源（上传/连接器/Web）、摄取阶段（隔离/扫描/解析/分块/向量化/索引/就绪/失败/阻断）、审核状态、版本、敏感级、所有者、新鲜度；失败可展开定位到具体阶段与错误码，提供"重试该文档"入口。
- **文档详情**：版本时间线（不可变版本 + 当前版本指针）、元数据（schema 驱动展示）、权限（继承来源与有效权限）、来源血缘（连接器/外部 ID/源 URL/同步游标）、预览。
- **预览/下载**：预览为受控渲染（excerpt/content 分级）；无下载权限不出现下载入口，不请求原始文件流。
- **元数据编辑**：表单由租户元数据 schema 驱动，支持必填/枚举/日期/多值/引用校验；批量编辑先预览差异再提交。

### 5.7 连接器中心与同步任务

- **连接器列表**：按能力卡片展示（授权状态、同步范围、同步模式 MANUAL/SCHEDULED/WEBHOOK、源 ACL 映射、数据区域、健康状态）。
- **配置流程**：OAuth 授权跳转 → 回调页不暴露第三方 token → 范围选择 → 首次全量同步预览 → 确认建连。
- **同步任务详情**：游标时间、新增/更新/删除/失败计数、新鲜度、限流状态；失败对象列表支持单对象重放与安全重试；源撤权/删除传播状态单独可见（撤权优先）。

### 5.8 治理中心

- **审核队列**：待审列表（提交人、敏感级、变更摘要）；审核操作附意见；批量操作先预览影响。
- **元数据与分类**：租户级 schema 管理（字段类型、必填、受控词表、分类层级）；变更需说明对存量文档的影响（如新增必填字段导致存量不可再发布）。
- **保留与法律保全**：策略列表、法律保全对象（阻断清理，醒目标识）、复审队列（到期内容清单，支持批量下线/延期）。
- **删除与证明**：删除审批流、删除任务进度（对象/索引/缓存/备份各阶段处置结果）、删除证明查询与导出（遵循最小权限与脱敏）。

### 5.9 权限编辑器

- 统一呈现知识库角色 + 文档 ACL；**可解释性**是核心：对任一用户/文档展示"最终有效权限 = 租户角色 ⊕ KB 角色 ⊕ 文档 ACL"的推导过程。
- 高风险变更（收窄大群权限、撤权）先预览影响文档数/成员数，确认后异步执行并跟踪传播状态；超传播 SLA 时页面提示该库问答已按安全策略暂停。

### 5.10 质量与用量 `/analytics`

- **质量面板**：按租户/业务域/语言/权限角色分层的 Recall@K、引用正确率、拒答准确率、ACL 泄漏率、延迟、成本；不展示掩盖细分退化的单一综合分。
- **用量与成本**：日维度搜索/问答/无答案趋势、按模型的 token 与成本、DAU、Top 文档。
- **配额**：存储/文档数/同步吞吐/查询并发/token 用量与上限，超限前预警。

### 5.11 管理中心

- **成员与组织**：全局用户 + 租户成员分离呈现；支持一人多租户；停用成员展示影响范围。
- **API Key**：scope、允许知识库、有效期、最近使用、吊销状态；创建明文**只展示一次**并需复制确认；吊销为危险操作三段式。
- **Webhook**：目标地址、事件类型、投递日志（成功/重试/死信）、签名轮换提示；禁止内网地址的前端即时校验（服务端复核为准）。
- **审计日志**：追加写语义呈现（操作者/动作/资源/结果/拒绝原因/requestId），支持按 requestId 串联 trace；导出需权限且脱敏。

## 6. 关键交互流程

### 6.1 上传文档到可检索（状态机外显）

```text
选择文件 → 预检(类型/大小) → 上传(幂等键) → [隔离] → [安全扫描] → [解析/OCR] → [分块] → [索引]
   → 元数据校验(schema 必填) → 提交审核(若开启) → 发布 → 可检索/可问答
                任一环节失败：定位阶段 + 错误码 + 重试/重新上传入口；BLOCKED 明示安全原因类别
```

### 6.2 租户切换

选择目标租户 → 确认切换 → 失效当前 tenant 域全部缓存与进行中的 SSE/轮询 → 重建上下文 → 回到工作台。切换中显示全局过渡态，禁止半切换状态下发请求。

### 6.3 授权失败统一处理

| 场景 | 表达 | 动作 |
| --- | --- | --- |
| 401 会话过期 | 全屏登录引导，保留当前路由 | 重新登录后回跳 |
| 403 无权限 | 页面/区块级提示 + 拒绝原因码 | 申请权限/联系管理员 |
| 404 或已删除 | 明确"不存在或已删除" | 返回列表 |
| 引用已撤回/过期 | 引用卡片置灰 + 原因 | 查看可用版本（若有权限） |
| 服务降级（策略服务不可用） | 明确"按安全策略暂不可检索"，不降级为全量结果 | 稍后重试/联系运维 |

## 7. 状态与异常设计规范（全站适用）

- 每页必备：loading（骨架屏优先）、empty（含引导动作）、error（错误码 + requestId + 重试）、disabled（说明原因）、stale（数据时间戳 + 刷新）、partial-success（批量操作逐条结果）、offline（只读提示，禁止提交）。
- 提交中防重复：按钮独立 loading + 幂等键；危险操作独立确认，不与普通保存共用交互。
- 长任务：进入任务中心，页面离开不丢失；完成后通知 + 结果摘要（成功/失败计数）。
- 敏感数据红线：不进入前端日志、埋点、URL query、错误上报；截图与测试数据脱敏。

## 9. 方案对比与推荐

### 9.1 认证与请求形态

| 方案 | 说明 | 优点 | 风险 | 结论 |
| --- | --- | --- | --- | --- |
| A. SPA + 浏览器持 token | 前端直连 API，内存存 token | 简单 | token 暴露面大，刷新令牌难安全保存，不符合 GKB-02 基线 | 不采用 |
| B. Next.js BFF + HttpOnly 会话（推荐） | BFF 完成 OIDC code 交换，浏览器只持有 Secure/HttpOnly/SameSite Cookie | token 不出服务端，天然 CSRF 可控，契合现有 Next.js BFF 定位 | 需实现 CSRF 防护与会话轮换 | **推荐，待契约评审确认 BFF 边界** |

### 9.2 UI 组件体系

| 方案 | 优点 | 风险 | 结论 |
| --- | --- | --- | --- |
| A. 自研组件 | 完全可控 | 成本极高，可访问性难达标 | 不采用 |
| B. 企业级组件库（Ant Design / TDesign 二选一） | 表单/表格/树/上传完备，AA 基线可达，中文生态成熟 | 主题定制需 tokens 规范 | **推荐**；二选一属工程决策，实现前确认 |
| C. Headless（Radix + 自绘） | 灵活 | 复杂组件（表格/树）自建成本高 | 不作为基线 |

### 9.3 推荐 MVP 切片（与需求分期对齐）

1. **Gate 0**：OIDC 登录/回调/登出、租户切换、统一 401/403/404、契约生成 client、SSE 问答骨架、预览/下载分级。
2. **企业 MVP**：工作台、知识库向导、文档库状态机、元数据 schema 表单、权限编辑器（可解释）、问答可信度与反馈、API Key 管理。
3. **通用化扩展**：连接器中心、同步任务、治理中心（保留/保全/删除证明）、分层质量面板。
