# 企业通用化运维基线

> **文档状态**：计划 · **版本**：v0.2-draft · **负责人**：待指定 · **最近更新**：2026-08-10
> **需求**：[`../requirements/README.md`](../requirements/README.md) · **测试**：[`../test/README.md`](../test/README.md)

本文件定义应在部署评审中冻结的运维门禁，不修改现有部署配置。

## 1. SLI/SLO 模板

| 能力 | SLI | 建议起始目标（待业务确认） |
| --- | --- | --- |
| 登录与授权 | 成功率、P95、策略错误率 | 可用性 99.9%；授权错误不能降级放行 |
| 搜索 | 成功率、P95、零结果率 | 可用性 99.9%；P95 按目标数据规模压测冻结 |
| 问答 | 首 token、完成率、P95、拒答率 | 流式完成率和业务域质量同时达标 |
| 摄取 | 接收成功率、解析成功率、端到端延迟 | 按文件类型/大小分层，不使用单一平均值 |
| 同步 | 新鲜度、积压、删除/撤权传播延迟 | 删除/撤权传播使用比内容更新更严格的 SLA |
| 策略索引 | policyVersion 落后量、二次校验剔除数 | 落后超过阈值暂停受影响库查询并告警 |

目标值必须基于首批交付形态、数据规模与业务等级确认；未确认前不得把建议值写成 SLA 承诺。

## 2. RPO/RTO 与备份恢复

- 分别为元数据/权限、原始对象、审计、会话、索引和配置定义数据等级、RPO、RTO、保留期和恢复责任人。
- PostgreSQL 使用全量备份 + WAL/PITR；对象存储启用版本、不可变/法律保全能力；配置与策略版本化。
- 向量/关键词索引默认可由不可变对象、文档版本和 outbox 事件重建；快照只用于缩短 RTO，不是唯一真相。
- 至少季度执行“空环境恢复”，校验租户/文档/版本/ACL/引用数量、索引可查询性和删除/保全状态。
- 备份加密并与生产凭证隔离；恢复权限、下载和演练日志纳入审计。

## 3. 安全运营

- 工作负载身份、OIDC client、API Key、Webhook secret、KMS key 和模型 provider key 分开轮换并设到期告警。
- 监控跨租户拒绝、ACL 二次剔除、策略版本落后、异常导出、批量下载、prompt injection/DLP 命中、模型路由越界和连接器撤权失败。
- 内容安全或授权组件不可用时新内容/受保护查询 fail-closed；禁止为恢复可用性临时关闭租户/ACL 过滤。
- Webhook/连接器出站统一 egress gateway；阻止 loopback、link-local、私网和云元数据地址，解析后与连接时均复核目的 IP。
- 审计存储使用追加写与独立访问控制；删除、导出、权限变更、身份同步、索引切换和密钥操作为高价值审计事件。

## 4. 发布与回滚门禁

- 发布制品固定镜像 digest 和依赖版本，禁止生产使用 `latest`；生成 SBOM 并通过漏洞、许可证和 secret 扫描。
- OpenAPI、migration、index profile、prompt、model/provider policy 均版本化；应用启动时验证兼容范围。
- 发布顺序：扩展兼容契约/数据 → 部署消费者 → 双写/双算观测 → 切换流量/别名 → 延迟清理旧版本。
- 回滚不得直接恢复已撤销权限或已删除内容；策略和内容安全变更回滚需要额外安全评审。
- 每次发布保留健康、业务、授权泄漏、质量、同步积压和成本验证；任一 P0 安全门禁失败立即停止或回滚。
