## 修复策略

1. 先备份并扫描无法转换、超长、空值和孤立数据。
2. 按数据库方言分别生成迁移脚本，不混用语法。
3. 在测试环境验证读写、索引、回滚和应用兼容。
4. 真实执行前确认精确表清单、窗口、负责人和回滚方案。
