# Feature Brainstorm

## Workflow

1. Read `.ai/project.json`, current role, relevant module docs, and nearby product behavior.
2. Identify goal, users, scenarios, constraints, current problems, and success measures.
3. Compare two or three feasible方案 when the direction is not obvious.
4. Recommend one MVP with reasons, tradeoffs, and validation.
5. List non-goals to prevent scope expansion.
6. End with unresolved decisions and the next artifact.

## Output

- 问题与目标用户
- 核心场景和流程
- 方案对比与推荐 MVP
- 不做范围
- 风险、验证和待确认问题

## Boundaries

- Do not edit implementation code in brainstorming mode.
- Do not freeze API or executable SQL without confirmation.
