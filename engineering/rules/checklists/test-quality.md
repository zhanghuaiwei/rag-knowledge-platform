# 测试与交付质量清单

## 测试分层

- [ ] 核心业务规则、状态流转、权限和边界条件有单元测试。
- [ ] API 路径、参数、响应适配和错误处理有契约或集成验证。
- [ ] 可见 UI 行为覆盖加载、空态、错误、权限、重复提交和危险操作确认。
- [ ] 外部服务、文件、消息和数据库失败路径有替身或受控环境验证。
- [ ] 测试不默认连接真实生产数据。

## 交付

- [ ] 已运行聚焦构建、静态检查、类型检查和测试，或记录跳过原因。
- [ ] 测试数据已清理，无法清理时已记录负责人和处理方式。
- [ ] 数据库、配置、权限、部署和外部系统影响已列出。
- [ ] UI 变化在可行时附截图或可复验路径。
- [ ] 遗留风险、环境限制和后续命令已明确，不夸大验证结论。
