# 前端功能任务清单

## 开始前

- [ ] 当前角色允许修改前端，且已查看 Git 状态。
- [ ] 已定位目标应用、同类页面、路由、请求封装、状态管理和测试方式。
- [ ] 已读取唯一 API 契约，不猜测字段、枚举、分页和权限。

## 实现

- [ ] API client、类型、页面状态、表单、权限和契约一致。
- [ ] 页面不直接拼接完整 API 地址，不创建重复请求封装。
- [ ] 输入校验、空值、时间、金额、精度和枚举显示语义明确。
- [ ] 覆盖 loading、empty、error、disabled、无权限和提交中状态。
- [ ] 删除、发布、批量操作等危险行为有确认、防重复和独立 loading。
- [ ] 新增/编辑保留关键标识，成功后刷新或更新本地状态。
- [ ] 可访问性、键盘操作、响应式布局和异常长文本经过基本检查。

## 收尾

- [ ] 已搜索旧 API、旧权限、旧字段和无用代码。
- [ ] 已运行聚焦 lint、typecheck、测试或记录原因。
- [ ] 可见 UI 变化已通过浏览器、截图或明确复验路径检查。
- [ ] 未验证的后端、权限和环境依赖已列为风险。
