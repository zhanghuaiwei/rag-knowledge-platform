# 需求与 API 契约清单

## 文档与状态

- [ ] 需求、设计和 API 契约位于 `docs/modules/<module>/` 对应目录。
- [ ] 同一功能只有一份当前有效需求和一份权威 API 契约。
- [ ] 契约标明草案、评审中、已确认或变更中状态及版本。
- [ ] 前端、后端和测试任务引用相同契约版本。

## 契约内容

- [ ] 路径、方法、认证、权限、幂等性和危险操作已定义。
- [ ] path/query/header/body、响应和分页结构已定义。
- [ ] 字段名、类型、必填、默认值、格式、示例和空值语义已定义。
- [ ] 枚举、状态流转、错误码和异常示例已定义。
- [ ] 导入导出、文件、时间、金额和精度等特殊语义已定义。

## 变更影响

- [ ] 变更原因和兼容策略已记录。
- [ ] 已检查前端、后端、数据、权限、测试、文档和发布影响。
- [ ] 破坏性变更有迁移、灰度或回滚方案。
