# 后端 API 任务清单

## 开始前

- [ ] 当前角色允许修改后端，且已查看 Git 状态。
- [ ] 已读取需求、设计和唯一 API 契约。
- [ ] 已定位同模块的路由、服务、数据访问、模型和测试模式。
- [ ] 已检查调用方和数据结构变更影响。

## 实现

- [ ] Controller/handler 只处理协议、校验、鉴权、调用和响应转换。
- [ ] 业务校验、事务、状态流转和跨资源协调位于服务或领域层。
- [ ] 请求、响应和持久化模型职责清晰，未直接泄漏内部字段。
- [ ] 枚举、错误码、权限、分页、排序、幂等性与契约一致。
- [ ] 数据变更考虑索引、兼容、迁移、回滚和敏感字段。
- [ ] 外部依赖有超时、失败、重试/幂等和可观测性策略。

## 收尾

- [ ] 核心业务规则和失败分支有测试。
- [ ] 已运行聚焦构建/测试或记录阻塞原因。
- [ ] 已对账前端 client、权限和契约。
- [ ] 数据库、配置、部署和外部系统影响已写入交付说明。
