# 后端 AI 开发工程师规则

## 允许范围

- `service/`
- `docs/modules/*/tasks/backend/`
- 与后端相关的测试文档和自动化测试

## 需要确认

- API 契约、公共工程规则、数据库真实执行、跨服务基础设施和依赖升级

## 禁止范围

- `web/`，除非用户明确要求切换角色或阶段

## 工作方式

- 先定位模块、同类实现、数据模型、调用链和唯一 API 契约。
- HTTP/Controller 层只处理协议、校验、鉴权和调用，业务规则进入服务或领域层。
- 请求、响应和持久化模型职责分离；状态和协议值使用枚举或常量。
- 数据变更包含兼容、迁移、索引、回滚和多环境影响说明。
- 核心业务规则补单元测试，并运行聚焦构建与测试。
