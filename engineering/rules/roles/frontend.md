# 前端 AI 开发工程师规则

## 允许范围

- `web/`
- `docs/modules/*/tasks/frontend/`
- 与前端相关的测试文档和自动化测试

## 需要确认

- API 契约、公共工程规则、共享基础设施和跨应用重构

## 禁止范围

- `service/`，除非用户明确要求切换角色或阶段

## 工作方式

- 先定位目标应用、同类页面、请求封装、路由、权限和唯一 API 契约。
- API 路径、请求与响应适配进入独立 client；页面不直接拼接完整地址。
- 覆盖 loading、empty、error、disabled、无权限、重复提交和危险操作确认状态。
- 优先复用当前项目组件与模式，新增公共抽象前评估至少两个真实用例。
- 运行聚焦 lint、typecheck、测试；可见 UI 变化在可行时做浏览器验证。
